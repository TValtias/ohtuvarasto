# ohtuvarasto

## Web-käyttöliittymä

Käynnistä Flask-sovellus komennolla `python src/app.py` ja avaa selaimessa
osoite http://127.0.0.1:5000. Käyttöliittymässä voi luoda varastoja sekä lisätä
niihin tavaraa ja ottaa sitä pois.
